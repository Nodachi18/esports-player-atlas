# Contributing

Thanks for helping improve Esports Player Atlas.

1. Open an issue for major changes so the approach can be discussed first.
2. Keep changes focused and document API or schema changes.
3. Run `npm run check` before opening a pull request.
4. Never include credentials, `.env` files, real voter data, or production databases.
5. Include reproducible steps for bug fixes and explain the statistical rationale for changes to aggregation or outlier detection.

This project is a prototype. Contributions that improve privacy, accessibility, test coverage, and resistance to vote manipulation are especially welcome.
