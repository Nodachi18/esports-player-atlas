# This is a public prototype with disposable data: anyone can rate, and a voter id is a
# resettable browser token. Keeping it out of search results until accounts exist, so the
# ratings here are not mistaken for anything authoritative.
#
# Note the interaction with the `X-Robots-Tag: noindex` in `_headers`: a crawler that obeys
# this file never fetches a page, so it never reads that header. The two signals cover
# different bots rather than reinforcing each other. If the goal becomes "crawl it, just do
# not list it" — the one case neither covers is a URL a search engine learned from a link
# elsewhere — allow the crawl here and let the header do the work.
#
# Delete this file to allow indexing.

# ---- Link previews ----
#
# The blanket Disallow above also stops the bots that build a link preview when someone
# pastes a URL into a chat. Most of them read this file, and a blocked fetch means no
# preview at all — so the Open Graph tags in index.html would be dead markup without the
# exceptions below.
#
# Allowing these is not a hole in the rule above. The tags are site-level: a scraper is
# served index.html whatever the URL says, routing happens in the browser, and the preview
# is a fixed title, a fixed sentence and /og.png. No player name, no rating, nothing about
# a real person reaches a preview. That changes the day the Worker renders per-player tags
# server-side, and these lines need revisiting then.
#
# Search crawlers are not on this list and stay disallowed.
